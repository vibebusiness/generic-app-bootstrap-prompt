# Generic App Bootstrap Prompt

A free, reusable starting prompt for building almost any app with an AI coding agent.

This project exists because criticizing “vibe coding” does not help beginners improve. The prompt gives an AI agent a disciplined way to understand a project before it starts changing code.

## What it helps the AI do

- Inspect the workspace before making changes
- Protect existing work and avoid destructive assumptions
- Define clear ownership and file-structure boundaries
- Create durable project instructions and supporting documentation
- Establish safety, maintenance, and verification rules
- Validate the foundation before feature work begins
- Leave a useful handoff for the next person or AI agent

## Use the prompt

1. Open **[PROMPT.md](PROMPT.md)**.
2. Copy the complete prompt.
3. Replace any bracketed placeholders you already know.
4. Paste it into your AI coding agent at the beginning of a new app—or when bringing an early app under better structure.
5. Let the agent inspect the workspace and ask questions before it begins implementation.

You can also [view the raw prompt](https://raw.githubusercontent.com/vibebusiness/generic-app-bootstrap-prompt/main/PROMPT.md) for easy copying.

## Who this is for

This is for beginners, independent builders, small teams, and anyone who wants to vibe code with more structure and fewer surprises.
